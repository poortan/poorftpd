# poorftpd
非常識なほど貧弱なFTPサーバー。<br>
ほとんどの人には無用です。<br>

## とにかく簡単に今すぐFTPサーバー！
今だけ別のPCに1個かそこらのファイルを送り込みたい。しかしUSBメモリ等の媒体が使えず、ネットワークには繋がっているならば、共有フォルダやFTPを利用したくなると思います。<br>
ただそのためだけに共有フォルダを作ったり、IISや著名なFTPサーバーをセットアップするのって、とても面倒くさいですよね。今だけ、たった1個のファイルの送受信を行いたいだけなのに！<br>
そんな、シンプルに今だけファイルを送受信したいニーズに応えるFTPサーバーです。<br>
もちろんTFTPが利用できれば、そっちがいいと思います。<br>

## 対応OS
C言語のみで書かれており、ソケットAPIを用いている他は特別なライブラリを使用しておらず、非常に軽量で実行ファイル単体で多くのOSで動くと思います。<br>
動作確認したOSを列挙します。<br>
- Microsoft Windows 11<br>
- FreeBSD 14.4<br>
- LinuxMint 22.2<br>
- Haiku OS R1/B5<br>

## 使い方
FTPサーバーにしたいPCで、次のようにして起動します。<br>
```
$ poorftpd ファイル名
```
ファイル名はサーバー側に存在するファイルを指定します。そのファイルがFTPクライアントが唯一発見できてダウンロードできるファイルとなります。<br>
ファイル名を省略すれば、全くファイルを発見できず、何もダウンロードできません。<br>
指定以外のファイルのダウンロードはもちろん、ディレクトリ移動も、削除や属性変更なども一切できません。<br>
<br>
ユーザー名、パスワードは何でも通ります。<br>
<br>
FTPクライアントからは任意のファイルをアップロード可能です。アップロード先はサーバー側のカレントディレクトリ固定です。<br>
<br>
終了させるには、Ctrl-C等で終了させるか、クライアントが切断すれば終了します。<br>
<br>
次のオプションがあります。<br>
-p ポート番号<br>
接続するポート番号をデフォルトの21から変更できます。<br>
<br>
-pp パッシブモードの待ち受けポート番号<br>
パッシブモード時はデフォルトで60000で待ち受けますが、これを変更します。<br>

```
$ poorftpd -p 8255 -pp 62256 FileName.txt
```
この例では、待ち受けポート番号8255、パッシブモード待ち受けポート番号62256という意味です。<br>

## 注意
前述の通り認証はありませんので、poorftpdが動いている間は、これ自体がセキュリティホールとなりえます。使い終えたら、速やかに終了させてください。<br>
複数クライアントからの同時接続はできません。<br>
FTPS（File Transfer Protocol over SSL/TLS）には対応していません。<br>
その他、多くのFTPサーバーが備えている機能の多くが使えません。<br>
